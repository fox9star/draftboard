# Draftboard

브라우저에서 바로 실행되는 로컬 디자인 도구입니다. 설치, 가입, 결제가 필요 없고 서버도 쓰지 않습니다.
파일은 브라우저 저장소(IndexedDB)에 저장되며, AI 기능은 내 컴퓨터에서 실행되는 [Ollama](https://ollama.com) 모델을 사용합니다.

**바로 써 보기:** <https://fox9star.github.io/draftboard/>

화면 테마는 라이트 · 그레이 · 다크 세 가지이며, 각 화면 위쪽의 테마 스위치나 에디터 메뉴(☰)에서 바꿀 수 있습니다.

모든 화면 오른쪽 아래의 **도우미**(말풍선 버튼)에게 사용법을 물어볼 수 있습니다. 로컬 AI(Ollama)가 연결되어 있으면 AI가 지금 보고 있는 화면을 참고해 답하고, 연결되어 있지 않으면 내장 도움말에서 답을 찾아 줍니다. 호스팅 사이트에서는 도우미의 **로컬 AI 연결** 버튼을 눌렀을 때만 이 PC의 AI에 접근합니다.

| 슬라이드 | 슬라이드 템플릿, 순서 바꾸기, 전환 효과, 발표자 노트, 슬라이드 쇼, PDF(인쇄) 내보내기 |

## 실행 방법

정적 파일만으로 이루어져 있어 빌드 과정이 없습니다. 이 폴더에서 로컬 서버를 띄우고 브라우저로 여세요.

```bash
python serve.py
```

`serve.py`는 브라우저가 매번 바뀐 파일을 확인하도록 해서, 코드를 고친 뒤 새로고침하면 바로 반영됩니다. `python -m http.server 8080`으로도 실행되지만 이전 파일이 캐시에 남아 한동안 보일 수 있습니다.

그다음 <http://127.0.0.1:8080> 에 접속합니다. 최신 Chrome 또는 Edge를 기준으로 만들었습니다.

### AI 기능 (선택)

AI 빌더와 미디어 플로의 AI 노드는 로컬에서 실행되는 Ollama 서버(`http://127.0.0.1:11434`)를 사용합니다.

```bash
ollama pull qwen2.5:7b        # 일반 모델
ollama pull qwen2.5-coder:7b  # 코드 생성 품질을 높이고 싶을 때
ollama pull llava             # ‘AI 이미지 설명’ 노드를 쓸 때 (비전 모델)
```

AI 빌더의 ⚙ 버튼에서 서버 주소와 문맥 길이를 바꿀 수 있습니다.

GitHub Pages 주소(`https://fox9star.github.io`)에서 AI 기능을 쓰려면, Ollama가 그 주소의 요청을 받도록 설정해야 합니다.

```powershell
# Windows: 사용자 환경 변수를 설정한 뒤 Ollama를 다시 시작합니다
[Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', 'https://fox9star.github.io', 'User')
```

macOS·Linux에서는 `OLLAMA_ORIGINS=https://fox9star.github.io`를 설정하고 Ollama를 다시 시작하세요. 브라우저가 “로컬 네트워크 접근”을 허용할지 물으면 허용해야 합니다.

## 저장과 공유

- 모든 파일은 브라우저의 IndexedDB에 자동 저장됩니다. 브라우저 데이터를 지우면 함께 사라지니 중요한 파일은 메뉴에서 JSON으로 내려받아 두세요.
- 파일 목록의 **가져오기**로 JSON 파일을 다시 열 수 있습니다.
- 파일 목록의 **백업**은 모든 파일을 백업 파일 하나로 내려받습니다. 다른 브라우저나 주소의 **가져오기**에 넣으면 한 번에 복원됩니다.
- 저장 공간은 브라우저와 접속 주소(예: `127.0.0.1:8080`)마다 따로입니다.
- 호스팅 사이트의 파일 목록에서 **이 PC 파일 가져오기**를 누르면, 로컬 서버(`127.0.0.1:8080`)에서 만든 파일을 바로 옮겨 올 수 있습니다. 새로 열리는 창에서 받는 주소를 확인하고 **보내기**를 누르세요. 같은 파일을 다시 옮기면 사본이 생기지 않고 최신 내용으로 갱신됩니다.

|---|---|
| 이동 / 손 도구 | `V` / `H`, `Space`+드래그 |
| 프레임 / 사각형 / 원 / 선 | `F` / `R` / `O` / `L` |
| 펜 / 연필 / 형광펜 | `P` / `Shift+P` / `M` |
| 텍스트 / 스티커 메모 / 연결선 / 스탬프 | `T` / `S` / `X` / `E` |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `home.css`, `home.js` | 소개 페이지 (에디터 체험 화면 포함) |
| `files.html`, `files.js` | 파일 목록: 만들기, 검색, 이름 바꾸기, 복제, 가져오기·내보내기, 삭제 |
| `editor.html`, `styles.css` | 에디터 화면 |
| `editor-core.js` | 문서 모델, 실행 취소, 저장, 캔버스·선택 영역 그리기 |
| `editor-input.js` | 도구, 마우스·키보드 입력, 편집 명령 |
| `editor-panels.js` | 레이어·슬라이드 패널, 디자인·프로토타입·모션·코드 탭 |
| `editor-present.js` | 프로토타입 재생과 슬라이드 쇼 |
| `editor-extra.js` | 모션 재생·동영상, 사이트, 대량 제작, 슬라이드 템플릿, 타이머, 메뉴, 시작 화면 |
| `scene.js` | 도형·텍스트 배치와 SVG 렌더링 (모든 화면이 공유) |
| `codegen.js` | HTML·CSS·React·Tailwind 코드와 반응형 사이트 생성 |
| `motion.js` | 애니메이션 효과와 이징 |
| `store.js` | IndexedDB 저장소 |
| `zip.js` | ZIP 묶기 |
| `serve.py` | 로컬 서버 (캐시 없이 항상 최신 파일 제공) |
| `ai.js` | 로컬 AI(Ollama) 연결 |
| `make.html`, `make.js` | AI 빌더 |
| `weave.html`, `weave.js` | 미디어 플로 |
| `ui.css` | 파일 목록·AI 빌더·미디어 플로 공통 스타일 |
| `theme.js` | 라이트·그레이·다크 테마 전환 (모든 화면이 공유) |
| `chat.js` | 도우미 챗봇 (로컬 AI 답변, AI가 없으면 내장 도움말 검색) |

## 지원하지 않는 것

- 실시간 공동 편집 (파일은 JSON으로 주고받습니다)
- 웹 호스팅 게시 (사이트는 HTML 파일로 내보냅니다)
- 이미지·동영상을 새로 그려 내는 생성형 AI (텍스트 생성과 이미지 설명만 지원합니다)
